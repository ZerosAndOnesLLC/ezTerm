# ezTerm v1.16.1

**Links in the terminal behave properly now.** Right-clicking a URL no longer pops up a "this link could potentially be dangerous" warning, so copy and paste work on links again. Left-clicking a link shows a small menu instead.

## What changed

### Fixes

- **Right-click on a link no longer opens it.** The terminal used to treat any mouse button as a link click, so right-clicking a URL to copy it showed a warning dialog instead of the Copy / Paste menu. Only a left click opens links now. Selecting text that starts on a link doesn't trigger it either.
- **No more "potentially dangerous" dialog.** Links that programs embed in their output (Claude Code, `ls --hyperlink`, compiler errors) used to show a browser warning box, and plain URLs didn't always open in your real browser.

### New

- **Link menu on left-click.** It shows the full address with **Open in browser** and **Copy link**, so you can see where a link goes before opening it.
- **Ctrl+click opens a link straight away**, like VS Code and Windows Terminal.

### Under the hood

- Links open through Tauri's official opener plugin. Only `http` and `https` addresses are accepted, and the app checks this again before passing the link to Windows.
