# ezTerm v1.16.2

**Maintenance release: every library updated to its latest stable version.** Nothing changes in how ezTerm looks or works. This release pulls in upstream fixes, including a SQLite security fix.

## What changed

### Security

- **Bundled SQLite updated.** sqlx 0.9.1 allows `libsqlite3-sys` 0.40, which fixes RUSTSEC-2026-0459 (uninitialized memory when opening a database with a mismatched `-wal` file). ezTerm only ever opens its own database, so it was never reachable, but the audit exception for it has been removed.

### Under the hood

- **SFTP library upgraded to russh-sftp 4.0.**
- **Rust:** sqlx 0.9.1, russh 0.65.4, hyper 1.13, plus the latest patch releases of the other Rust libraries.
- **UI:** lucide-react 1.80, vitest 5.1.2, autoprefixer 10.7, plus updated type definitions. TypeScript stays on 6.0 until the lint tooling supports TypeScript 7.
