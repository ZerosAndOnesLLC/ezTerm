# ezTerm v1.12.2

Maintenance release — every dependency refreshed to its latest stable version and dead Windows-only crates removed. No behavior changes.

## Maintenance

- **argon2 0.5 → 0.6** — vault key derivation API is unchanged; the on-disk vault format is unaffected.
- **Tauri plugins** — updater 2.11, dialog 2.7.3, clipboard-manager 2.3.3 (Rust and JS sides kept in step).
- **Frontend** — Next 16.3.4, React 19.3, lucide-react 1.44, and all types and tooling within their current majors.
- **Website** — Astro 7.3.2, Starlight 0.42, isomorphic-dompurify 4, vitest 5.
- Removed the unused `windows` / `windows-core` crates left behind when the OLE drag-out experiment was dropped in v1.6.9.

## Security

- `npm audit` reports zero vulnerabilities for both the app UI and the website.
- `cargo audit` findings are unchanged from v1.12.1: quick-xml 0.38 (pinned by rust-s3, latest), rsa (Marvin, via the SSH key stack), and glib 0.18 (Tauri's Linux GTK stack). None has an upstream fix yet.

## Held back

- eslint 10 and TypeScript 7 — `eslint-config-next` and `typescript-eslint` do not load with them yet.
