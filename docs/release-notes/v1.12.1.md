# ezTerm v1.12.1

Security and maintenance release — every dependency updated to its latest stable version, clearing all fixable security advisories. No behavior changes.

## Security

- **russh 0.61 → 0.62.7** — picks up upstream fixes for four advisories in the SSH stack.
- **quinn-proto** (high-severity advisory) is no longer in the dependency tree at all.
- Frontend and website dependency advisories (js-yaml, svgo, dompurify) cleared; `npm audit` now reports zero vulnerabilities across the project.

## Maintenance

- **sqlx 0.8 → 0.9** — dynamic query strings are now explicitly audit-wrapped under sqlx's new injection-safety API.
- **chacha20poly1305 0.10 → 0.11** — vault crypto migrated off deprecated constructors; on-disk vault format is unchanged.
- All remaining Rust and npm dependencies updated to latest stable within their majors.
