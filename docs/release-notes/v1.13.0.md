# ezTerm v1.13.0

A **Settings panel**, **OSC 52 clipboard support** so Claude Code, neovim and tmux can copy to your clipboard over SSH, a **resizable file pane**, a tab strip that **scrolls instead of collapsing**, faster terminal output, continuous integration, and a full dependency refresh that clears every open security advisory with an upstream fix.

## What changed

### Settings panel (#166, #5)

Open it from the sidebar menu or the new gear in the status bar. Every control saves as you change it.

- **Terminal** — defaults for new sessions (scrollback lines, font size and family, cursor style and blink), copy on select, right-click as menu or paste (Ctrl + right-click always opens the menu), a warning before pasting multiple lines, the OSC 52 clipboard switch, and a bell that can flash the terminal or beep.
- **Sessions** — confirm before closing a connected tab, confirm on quit with connected tabs, open the file pane automatically on connect, default keepalive and connect timeout.
- **Appearance** — theme, and tab labels as session name or `user@host`.
- **Updates** — check on launch, check interval, and the pre-release channel, which moves here from the update dialog.
- **Security** — **idle auto-lock**: lock the vault after a chosen number of minutes without keyboard or mouse input.

### Clipboard writes from remote programs (#164)

The terminal now honours **OSC 52**, the escape sequence programs use to copy to the terminal's clipboard. Claude Code's copy action, neovim's `+` register over SSH, and tmux's `set-clipboard` all land on your local clipboard. Reads are refused, so a remote host can never pull your clipboard contents. Switch it off under Settings → Terminal.

### Resizable file pane and scrollable tabs (#26, #154)

- The SFTP pane has a drag handle on its right edge (200–640 px, remembered). Double-click resets it. Keyboard users can focus the handle and use the arrow keys.
- With many tabs open, tabs now shrink to a readable floor and then the strip scrolls — mouse wheel, edge chevrons, and the active tab is always kept in view — instead of collapsing to icon stubs.

### Faster terminal output (#18)

Shell output travels from Rust to the terminal as raw bytes over a Tauri IPC channel instead of a JSON array of numbers. Bulk output such as `cat` on a large log is noticeably quicker, and the first bytes of a session can no longer race the listener.

### Smaller fixes

- Closed tabs show **"Disconnected (exit N)"** when the shell exited with a non-zero status (#21).
- Duplicating a session copies it and its environment rows in one database transaction (#4).
- Composite indexes for folder and session ordering (#2); SQLite is opened from the path rather than a URL (#9); explicit `script-src` in the CSP (#8).
- The unused SCP stub commands are removed (#23).

### Under the hood

- **Continuous integration**: every pull request now runs `cargo check` with warnings as errors, clippy, the Rust tests, `cargo audit`, UI typecheck / lint / tests / build, and the site build and tests (#7).
- First UI unit tests (vitest): the OSC 52 parser and the settings store.
- Dependencies: russh 0.64, russh-sftp 3.0, Tauri 2.12 and plugins, Next.js 16.4, ESLint 10, Astro 7.3.8, and all patch bumps. Clears the open advisories for russh, Next.js, devalue and DOMPurify.

## Known follow-ups
