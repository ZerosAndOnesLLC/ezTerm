# ezTerm v1.15.1

**Terminal text no longer gets cut off in narrow windows.** With several tabs open, a window snapped to half a monitor (or otherwise made narrow) showed the right edge of the terminal and the view toolbar clipped. It now always fits the window.

## What changed

### Fixes

- **Narrow windows with many tabs fit properly (#190).** The window used to grow wider than the screen to make room for every tab, which clipped the view toolbar and made the terminal pick more columns than were visible. Now the window keeps its real width. The tab strip scrolls (mouse wheel or the ‹ › buttons), the toolbar stays fully visible, and the terminal wraps at the visible edge.

### Under the hood

- **Dependencies updated:** Next.js 16.4.6, Tauri 2.12.6, plus the latest patch releases of the UI and Rust libraries.
- **Removed an unused Rust dependency.**
