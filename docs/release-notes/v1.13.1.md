# ezTerm v1.13.1

**Resizable columns in the SFTP pane**, a hardened terminal output path that no longer writes into closed tabs or hangs on an early shell prompt, a stall watchdog, and consistent release asset names.

## What changed

### Resizable file-pane columns (#174)

Long filenames were cut off with no way to widen the column. The **Name** and **Size** headers now have a drag handle on their right edge. Double-click resets a column, and keyboard users can focus the handle and use the arrow keys. Once the columns outgrow the pane the list scrolls sideways instead of truncating. Widths are remembered across restarts, like the pane width.

### Terminal output channel (#170)

Follow-ups to the raw-bytes output path that shipped in v1.13.0.

- **No writes into a closed terminal.** The output channel is detached before the terminal is disposed, and on every cancel and retry path, so closing a tab mid-stream can no longer throw.
- **No hang on an early prompt.** Output is buffered from the moment the channel exists and only released once the keystroke handler is wired, so a shell that sends a cursor-position query on startup always gets its answer. The separate local-shell ready gate this replaces is removed.
- **Stall watchdog.** Rust counts the chunks it sends per connection and the terminal polls every 3 seconds. If Rust is ahead with no progress on the receiving side across two polls, the tab fails with a visible error instead of sitting silent.
- Exit by signal is shown as "Disconnected (killed by SIGKILL)" and similar, and a close without a status no longer erases an earlier error message.
- Duplicating a session now copies its port forwards in the same transaction.
- One keystroke listener per connection instead of one per reconnect.

### Release asset names (#171)

Every published file follows `ezTerm_<version>_<platform>…`, including the portable archives and the macOS updater bundle. The v1.13.0 assets were renamed in place; updater URLs in `latest.json` follow the new names.
