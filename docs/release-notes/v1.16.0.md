# ezTerm v1.16.0

**ezTerm is getting ready for the Microsoft Store.** Each release now includes an MSIX package for the Store. Store installs are updated by the Store and include VcXsrv for X11 forwarding.

## What changed

### New

- **Microsoft Store package.** The Windows build now also produces `ezTerm_<version>_windows-x64.msix`, which is submitted to the Microsoft Store.
- **Store installs leave updates to the Store.** When ezTerm runs as a Store install, it hides the update button and Settings → Updates, and the built-in updater stays off. GitHub installs (MSI, NSIS, portable) keep updating themselves as before.

### Under the hood

- **Install channel detection.** The app checks at startup whether it was installed from the Store, using one Windows call and no new dependencies.
