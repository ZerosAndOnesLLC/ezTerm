# ezTerm v1.14.0

**Persistent SSH sessions with tmux or screen, and automatic reconnect.** A dropped connection, a laptop going to sleep or a closed tab no longer costs you your work. Reconnect and you're back exactly where you left off. Plus 17 terminal colour palettes to choose from.

## What changed

### Persistent sessions (#181)

Open a session's settings, go to **Advanced → Persistent session** and pick **tmux** or **screen**. The shell then runs inside a session on the server that keeps going when ezTerm disconnects.

- **Reconnecting puts you back where you were:** same shell, running jobs and open editor. Starting directory and initial command run only when the remote session is first created, never on reattach.
- **Each tab gets its own remote session.** Close a tab and open the session again later, and it reattaches to the one that tab left running, even after restarting ezTerm.
- **Sessions are private to this install.** Their names include a random id for this copy of ezTerm, so other people or machines using the same server account never attach to yours.
- **End remote session.** Closing a tab only detaches. To stop a remote session, right-click in the terminal and choose **End remote session…**.
- **If tmux or screen isn't installed** (or the server can't be checked), you get a normal shell and a one-line notice in the terminal.

Scrollback now lives in tmux or screen, so ezTerm's own scrollback and Find only see what has been drawn on screen. For mouse-wheel scrolling in tmux, add `set -g mouse on` to `~/.tmux.conf` on the server. ezTerm never edits remote config files.

### Automatic reconnect (#181)

Tick **Reconnect automatically if the connection drops** in the same section. It's on by default once you pick tmux or screen, and it also works with a normal shell.

- It only kicks in when the link really drops (keepalive timeout, network loss, server restart). Typing `exit` or detaching from tmux closes the tab as usual.
- Retries back off from 1 s to 30 s with a little random variation, so many tabs don't all reconnect at the same moment. It gives up after 20 attempts and shows the last error.
- The overlay shows the attempt count with **Retry now** and **Cancel**.
- Host-key prompts, login failures and a locked vault stop the retries right away. ezTerm never trusts a host key on its own, and never keeps retrying a rejected login.
- Set a keepalive on the session so a dead link is noticed quickly. The dialog warns you if keepalive is off.

### Terminal colour palettes (#176)

Pick the terminal's colours in **Settings → Appearance → Terminal colours**. There are 17 built-in palettes: ezTerm Dark (the existing default, unchanged) and ezTerm Light, Campbell (Windows Terminal), Solarized Dark and Light, Dracula, Gruvbox Dark, Nord, One Dark, Monokai, Tango, and the GNOME, GitHub and Google dark and light pairs from Ptyxis.

- A preview strip shows a sample prompt and all 16 colours, and every open tab repaints immediately.
- The palette is separate from the dark/light app theme, so switching the app to light mode leaves your terminal colours alone.
- The choice is saved with your other settings and included in backups and sync.

Thanks to @the-angwe for this one (#178).

### Under the hood

- Pull requests now run checks only; full builds run when a release is published (#180).
- Clippy is now a blocking check, and the existing clippy warnings are fixed.
- Dependencies updated to the latest stable versions (russh 0.65.1, Next.js 16.4.5, React 19.3.1, ESLint 10.14, Astro 7.4.5 and more). TypeScript stays on 6.0 until typescript-eslint supports 7.
