ezTerm ships 17 built-in colour palettes for the terminal. The palette sets the 16 ANSI colours plus the background, text, cursor and selection colours for every terminal tab.

## Change the palette

Open **Settings → Appearance → Terminal colours** and pick a palette. A preview strip under the menu shows a sample prompt and all 16 colours. Every open tab repaints immediately; there's no need to reconnect.

The choice is saved with your other settings, so it's included in backups and sync.

## Terminal palette vs app theme

The terminal palette is separate from ezTerm's dark/light app theme (**Settings → Appearance → Theme**). Switching the app to light mode doesn't change the terminal colours, so a terminal you've set up the way you like stays that way. Pick a light palette if you want a light terminal too.

Some upstream palettes use very pale yellow or white on a light background, so output in those colours can be hard to read. If that bothers you, try **ezTerm Light** or **Solarized Light**.
